# rileyy v1.0.0 Portfolio Site

No-frills SPA built in `react-ts` and hosted with Vercel at [rileyy.vercel.app](https://rileyy.vercel.app/). Thanks for taking a look!

Includes links to: this GitHub, my LinkedIn, my email, and my resume PDF.
